# Business Analytics – Investment Analysis

## 📊 Project Overview

This project analyzes investment preferences and financial behavior using survey data from 40 respondents.

The analysis was completed using Python, Pandas, Matplotlib, and Seaborn. It covers data exploration, descriptive statistics, investment preferences, savings objectives, investment duration, expected returns, and correlation analysis.

## 🎯 Objectives

- Understand investment preferences
- Analyze demographic information
- Identify common investment avenues
- Study reasons for different investments
- Analyze savings objectives
- Examine investment duration
- Analyze expected returns
- Study relationships between age, investment duration, and expected returns

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- CSV Dataset
- Jupyter / VS Code
